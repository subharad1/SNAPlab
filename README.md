# SNAPlab

Contains 3 folders for 3 related folders as listed below

## Projects

### [EEG correlates of auditory selective attention in hearing loss](eeg-attention/)
EEG time-series analysis (alpha lateralization, evoked potentials) comparing
attentional control in normal-hearing and hearing-impaired listeners.

### [Executive function and speech-in-noise perception](exec_func-SIN/)
Regression models relating working memory and inhibitory control to
speech intelligibility under energetic and informational masking (N = 200).

### [Distorted Tonotopy Vocoder](dt-vocoding)
A vocoder designed to manipulate auditory filter Tip-to-Tail Ratio (TTR) to simulate distorted tonotopy in Normal Hearing Participants
